# שני צדדים · העלאה ל-App Store ול-Google Play

בתיקייה הזו יש כל מה שצריך: פרויקט אפליקציה מוכן לאייפון ולאנדרואיד, אייקונים ומסכי פתיחה בכל הגדלים, צילומי מסך לחנויות, טקסטים לדף האפליקציה, הערות לבודקים של אפל ותשובות לשאלוני הפרטיות.

## מה צריך מראש

| | אייפון (App Store) | אנדרואיד (Google Play) |
|---|---|---|
| חשבון מפתח | Apple Developer Program, 99$ לשנה. אישור לוקח 1–2 ימים | Google Play Console, 25$ חד-פעמי. אימות זהות לוקח כמה ימים |
| מחשב | Mac עם Xcode 16 ומעלה | כל מחשב עם Android Studio |
| בדיקה של החנות | בדרך כלל 1–3 ימים | חשבון אישי חדש: חייבים קודם בדיקה סגורה עם 12 בודקים במשך 14 יום. חשבון ארגוני פטור |
| תוכנות | Node.js 20 ומעלה | Node.js 20 ומעלה |

## שלב 1: הכנה (פעם אחת)

```bash
cd app-build
npm install
npm run sync        # מעתיק את האתר העדכני לאפליקציה ומעדכן את שני הפרויקטים
```

`npm run sync` לוקח את הקבצים מהתיקייה `../shnei-tzdadim/site` (הריפו מ-GitHub). אם הריפו שמור במקום אחר, הריצו `SITE_DIR=/הנתיב/לתיקיית/site npm run sync`. אם אין ריפו בכלל, התיקייה `www` כבר מכילה עותק עדכני והאפליקציה תעבוד איתו.

## שלב 2: אייפון

1. `npm run ios` פותח את הפרויקט ב-Xcode.
2. בחרו את הפרויקט App ← לשונית **Signing & Capabilities** ← **Team**: החשבון שלכם. מזהה האפליקציה הוא `com.shneitzdadim.app`. אם הוא תפוס, שנו אותו גם כאן וגם ב-`capacitor.config.json`.
3. חברו אייפון ולחצו ▶ כדי לנסות. בפעם הראשונה Xcode מוריד את חבילות Capacitor, וזה לוקח דקה.
4. ב-App Store Connect: **My Apps ← + ← New App**, שם "שני צדדים", שפה ראשית עברית, אותו Bundle ID.
5. ב-Xcode: בחרו **Any iOS Device** ← **Product ← Archive** ← **Distribute App ← App Store Connect ← Upload**.
6. ב-App Store Connect מלאו את דף האפליקציה:
   - **טקסטים:** הכל מ-`store/listing-he.txt`.
   - **צילומי מסך:** `store/screenshots/ios-6.9-1.png` עד `6`, בגודל 6.9 אינץ'.
   - **פרטיות:** `store/privacy-answers.txt`.
   - **הערות לבודקים:** `store/review-notes.txt`. יש שם קודים של חתונת דמו שכבר הכנתי בשרת.
   - **כתובת מדיניות פרטיות:** https://shlomigu.github.io/shnei-tzdadim/privacy.html
7. בחרו את הגרסה שהעליתם ולחצו **Submit for Review**.

## שלב 3: אנדרואיד

1. `npm run android` פותח את הפרויקט ב-Android Studio. בפעם הראשונה הוא מוריד את Gradle, וזה לוקח כמה דקות.
2. **Build ← Generate Signed App Bundle ← Android App Bundle** ← צרו מפתח חדש (keystore). **שמרו את הקובץ ואת הסיסמה. בלעדיהם אי אפשר לעדכן את האפליקציה אף פעם.**
3. ב-Play Console: **Create app** ← שם "שני צדדים", חינם.
4. מלאו את דף האפליקציה:
   - **טקסטים:** מ-`store/listing-he.txt`.
   - **אייקון:** `store/screenshots/play-icon-512.png`.
   - **תמונה ראשית (Feature graphic):** `store/screenshots/play-feature-graphic.png`.
   - **צילומי מסך:** `store/screenshots/android-phone-1.png` עד `6`.
5. **Data safety** ו-**Content rating**: התשובות ב-`store/privacy-answers.txt`.
6. העלו את קובץ ה-`.aab` למסלול **Internal testing** כדי לנסות, ואחר כך ל-**Production**.

## שלב 4: עדכונים בעתיד

השינויים באתר מגיעים לאפליקציה רק אחרי `npm run sync` והעלאה של גרסה חדשה. בכל גרסה מעלים את מספר הגרסה:
- **iOS:** ב-Xcode, Version ו-Build.
- **Android:** `versionCode` ו-`versionName` ב-`android/app/build.gradle`.

## מה כבר מוגדר בפרויקט

- **שם ושפה:** "שני צדדים", עברית ומימין לשמאל.
- **iOS:** הודעות הרשאה בעברית למצלמה, מיקרופון וגלריה (בלעדיהן אפל דוחה), אייפון בלבד (כך לא דורשים צילומי מסך לאייפד), אייקון בלי שקיפות.
- **Android:** יעד Android 15 כפי שגוגל דורשת, הרשאות מצלמה, מיקרופון ומדיה.
- **שמירה לגלריה:** כפתור "שמירה" באפליקציה פותח את גיליון השיתוף של המכשיר ("שמור תמונה" / "שמור סרטון").
- **קישורי הזמנה:** מהאפליקציה הם תמיד מובילים לאתר, כך שגם מי שאין לו את האפליקציה יכול להצטרף.
- **אייקונים ומסכי פתיחה:** בכל הגדלים, כולל מצב כהה. המקור ב-`assets/`, ואפשר ליצור מחדש עם `npm run assets`.

## דברים שאפל עלולה להעיר עליהם

- **סעיף 4.2 (אפליקציה שהיא רק אתר):** אפל דוחה לפעמים אפליקציות שעוטפות אתר. לטובתנו עומדים צילום מהמצלמה, שמירה לגלריה, שיתוף מערכת ומסך פתיחה. אם בכל זאת ידחו, אפשר להוסיף התראות push כשמגיע טיזר או ברגע החשיפה, וזה בדרך כלל מספיק.
- **סעיף 1.2 (תוכן שמשתמשים מעלים):** אפל מבקשת דרך לדווח על תוכן פוגעני ולחסום משתמש. החתונה סגורה לבעלי קוד, וזה עוזר, אבל אם יבקשו, אוסיף כפתור "דיווח" בתמונה ואפשרות להסיר משתמש.
- **סעיף 5.1.1 (מחיקת משתמש):** אם יבקשו מחיקת משתמש מתוך האפליקציה, אפשר להוסיף כפתור "מחיקת המשתמש שלי" בהגדרות.
