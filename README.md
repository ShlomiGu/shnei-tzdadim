# שני צדדים

אפליקציית יום החתונה לחבורת החתן וחבורת הכלה: כל צד מצלם לעצמו, שולח טיזרים מטושטשים, והכל נחשף בחופה.

**האתר:** https://shlomigu.github.io/shnei-tzdadim/

- מי שפותח חתונה מקבל שני קודים, אחד לכל חבורה. כל מי שמצטרף עם קוד נכנס לחבורה שלו.
- הפרטיות נאכפת בשרת (Supabase): עד רגע החשיפה, הצד השני לא מקבל בכלל את הכתובות של התמונות.
